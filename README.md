# Visionote 📝

A modern sticky notes platform built with **FastAPI**, **MongoDB Atlas**, and **React (Vite) + Tailwind CSS**.

---

##  Quick Start

### 1. Backend
```bash
cd backend
python -m venv vnote-env && .\vnote-env\Scripts\Activate.ps1   # (Linux/macOS: source vnote-env/bin/activate)
pip install -r requirements.txt
uvicorn app.main:app --reload

### 2. Frontend
```bash
cd frontend
npm install
npm run dev
```
